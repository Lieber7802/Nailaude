# Nailaude Technical Debt

## M2 UI Interaction Debt

> 记录时间：2026-05-28  
> 背景：M2 UI polish 后，界面中出现了一些为完整产品体验预留的入口。当前阶段先实现纯前端可完成的交互；需要后端状态、业务流程或独立模块支持的功能记录在这里，防止遗忘。

| 入口 | 当前状态 | 预期功能 | 建议阶段 |
|---|---|---|---|
| `+ 添加代理` chip | 视觉保留，暂不触发 | 打开参与 Agent 管理；后续支持添加内置 Agent 或自定义 Agent 到当前会话 | M5 自定义 Agent / 会话管理 |
| 编辑会话标题 | 按钮显示，暂未实现 | 内联重命名或弹窗重命名当前会话，并调用 conversation update API | M2 后续 polish |
| 更多操作 `...` | 按钮显示，暂未实现 | 打开会话菜单：删除、导出、清空消息、复制会话信息 | M5 体验打磨 |
| 设置 | 按钮显示，暂未接路由 | 跳转或打开设置页，展示平台配置、主题和基础偏好 | M5 设置页 |
| 查看全部对话 | 按钮显示，暂未实现 | 打开完整对话管理视图，支持分页、筛选、归档 | M5 体验打磨 |
| `@ 代理` 快捷按钮 | 按钮显示，暂未实现 | 聚焦输入框并打开 Agent mention selector | M2 后续 polish |
| `/ 命令` 快捷按钮 | 按钮显示，暂未实现 | 打开快捷命令面板，如生成页面、审查代码、总结会话 | M5 命令面板 |
| 附件 | 按钮显示，暂未实现 | 选择文件并作为上下文/附件发送给 Agent | P1/P2，取决于 Demo 需要 |
| 更多发送选项 | 按钮显示，暂未实现 | 打开发送模式菜单，如指定调度、仅保存草稿、选择执行策略 | M5 体验打磨 |
| Preview 文件名按钮 | 按钮显示，暂未实现 | 展开当前会话产出物/文件选择器 | M4 Preview 增强 |
| 展开预览 | 按钮显示，暂未实现 | 打开全屏预览或扩大右侧预览面板 | M4 Preview 增强 |
| 真实在线人数 | 暂不展示 | 由后端 `presence_update` 或 WS connection manager 推送真实在线状态 | M3/M5 后端状态增强 |
| Agent 平台健康状态 | 暂不展示 | 由 AgentManager/platform healthcheck 提供真实可用性 | M3 Adapter 接入 |
